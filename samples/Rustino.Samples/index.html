Menus & System Tray

Application Menu

The menu bar above is set via SetMenu(). It includes submenus, check items, separators, keyboard accelerators and an item with an icon (Help › Documentation). On macOS the Window menu lists the open windows and the Help menu has a search field.

SetMenuItemEnabled(), SetMenuItemText() and SetMenuItemChecked() change items without rebuilding the menu. Show Sidebar is also in the tray menu: both stay in sync.

Context Menu

Shown at cursor position via ShowContextMenu().

System Tray

A tray icon is registered via SetTrayIcon() with a tooltip and menu. Left-click the tray icon to show the window, right-click it for the menu. On macOS the icon is a template that follows the menu bar's colors.

SetTrayTitle() shows text next to the icon (macOS and Linux).

Reactive Observables

Rustino exposes IObservable<T> streams for all events. The Reactive extension library adds throttling, filtering, and completion helpers. Watch the console output as you interact.

Message Routing by Prefix

WhenWebMessageWithPrefix("cmd:") filters messages by prefix.

Observables Active

  • • WhenSizeChangedThrottled (300ms) — resize the window
  • • WhenPageLoadCompleted — fires on page finish
  • • WhenFocusChangedDistinct — focus/blur the window
  • • WhenWebMessageWithPrefix("cmd:") — filtered messages
  • • WhenWindowClosed — fires on close

Launch & Activation

Single Instance

RustinoSingleInstance.Acquire() runs at startup. Run the sample again (dotnet run -- hello world): the new process forwards its arguments here, SecondInstanceStarted logs them and the window is activated.

Deep Links

AttachDeepLinks(single, "rustino-sample") routes matching URLs through UrlsOpened, from the first launch and from later ones: dotnet run -- rustino-sample://open?id=42. Registering the scheme with the OS is up to the app's installer.
